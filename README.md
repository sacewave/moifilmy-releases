# Мои фильмы — релизы

**Мои фильмы** — Android-приложение для учёта фильмов, сериалов и аниме: отметки «просмотрено», оценки, списки, статистика, профили, друзья и чаты.

## Как установить

1. Скачайте файл `MoiFilmy-*.apk` из нужного релиза на телефон с Android 7.0 или новее.
2. Откройте файл и разрешите установку из этого источника, если Android попросит.
3. Нажмите «Установить». Новая версия ставится поверх старой — ваши данные сохраняются.

Если приложение уже установлено, обновление можно скачать прямо в нём: Профиль → ⚙ Настройки → «Обновление приложения» → «Проверить обновления».
